# Third-party components

Andrew's code is GPL-3.0-or-later. Dependencies, external clients, and separately downloaded model weights retain their own licenses. No account credentials or trained speech weights are included in releases. Check accompanying model cards before redistributing downloaded weights.

- [Sherpa ONNX](https://github.com/k2-fsa/sherpa-onnx): keyword spotting, Parakeet inference, speaker matching.
- [NVIDIA Parakeet](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3): recognition.
- [Faster Whisper](https://github.com/SYSTRAN/faster-whisper): optional recognition.
- [Kokoro ONNX](https://github.com/thewh1teagle/kokoro-onnx): fast local speech.
- [Piper](https://github.com/OHF-Voice/piper1-gpl) and individual [voice model cards](https://huggingface.co/rhasspy/piper-voices).
- [Chatterbox](https://github.com/resemble-ai/chatterbox): optional expressive speech.
- [python-chess](https://github.com/niklasf/python-chess): chess rules, GPL-3.0-or-later.
- [Gradle](https://github.com/gradle/gradle): build wrapper, Apache-2.0. Android tools installed separately.

Grok Build, Claude Code, Codex, Ollama, Home Assistant, Chromium, and Google Voice are independent products. Andrew does not redistribute proprietary AI clients or include a subscription. Account compatibility and limits are determined by each provider. Installation links refer to official distribution channels.
